# AI English Chat Backend

Backend-часть приложения для практики английского языка. Обеспечивает работу чатов, интеграцию с LLM для генерации ответов и оценки речи, хранение истории сообщений и обработку аудио.

## Возможности

- **Управление пользователями**: Регистрация и аутентификация через JWT для безопасного доступа к истории чатов.
- **Чат**: API для управления чатами (создание, получение списка, удаление) и обмен сообщениями через WebSocket для интерактивного взаимодействия в реальном времени.
- **Интеграция с LLM**: Генерация ответов, перевод текста, детальная оценка грамматики и речи с объяснениями.
- **Обработка аудио**: Распознавание речи с использованием Whisper JNI для преобразования голоса в текст.
- **Хранение данных**: PostgreSQL с использованием JPA и миграций Flyway для надежного сохранения истории переписки.

## Архитектура

Проект построен по принципу feature-based архитектуры, где код организован по функциональным модулям (features). Каждый модуль содержит свои слои, что обеспечивает четкое разделение ответственности внутри функциональности.

### Организация слоев внутри фичи:

| Слой | Назначение |
| :--- | :--- |
| `controller` | Обработка HTTP и WebSocket запросов модуля |
| `service` | Бизнес-логика модуля |
| `entity` | Сущности БД, относящиеся к модулю |
| `dto` | Объекты передачи данных модуля |

### Основные функциональные пакеты (модули):

| Пакет | Назначение |
| :--- | :--- |
| `auth` | Аутентификация, авторизация, управление JWT-токенами |
| `chat` | Управление сессиями чатов (создание, получение списка, удаление) |
| `common` | Общие компоненты: исключения, конфигурации безопасности, утилиты |
| `llm` | Интеграция с LLM, генерация ответов, шаблоны промптов |
| `message` | Обработка сообщений внутри чатов, отправка/получение |
| `transcription` | Транскрипция аудиофайлов (распознавание речи) |
| `user` | Управление данными пользователей |
| `websocket` | Настройка и обработка WebSocket-соединений |

### Структура проекта

- `src/main/java/com/example/aienglishchatbackend` — основной исходный код с функциональными модулями.
- `src/main/resources` — конфигурации (`application.properties`) и миграции (`db/migration`).
- `src/test` — модульные и интеграционные тесты.

## Запуск локально

### Требования

- Java 21.
- Запущенная база данных PostgreSQL (необходимо заранее создать БД с именем `ai_assistant_db`, либо запустить её через Docker).
- Настроенные переменные окружения для подключения к LLM (или заглушка).
- На компьютере должен быть файл модели по пути `models-path/ggml-small.en.bin` для работы Whisper JNI.

### Установка и запуск

```bash
# Сборка проекта
./mvnw clean package

# Запуск
java -jar target/ai-english-chat-backend-0.0.1-SNAPSHOT.jar
```
